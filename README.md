# ヒトログ

公開版: https://kantaro08.github.io/hitolog/
リポジトリ: https://github.com/Kantaro08/hitolog
人脈管理ではなく、身近な人を思い出すための「人物図鑑」アプリです。人物データは端末内に保存します。

## 主な機能

- 登録人数・情報完成度・タグ・今日の発見を眺める人物図鑑ホーム
- 名前・会社・部署・役職・タグ検索
- 写真、会社、部署、役職、趣味、覚えておきたいこと、次回聞くこと
- 日付・場所ごとの会話タイムライン
- 使用人数つきタグ分類、メイン趣味の★設定、タグからの人物一覧表示
- JSONバックアップ／復元
- 4〜8桁PINによるアプリロック
- 対応端末のTextDetectorを使った端末内名刺読み取り
- メモと会話から次回の質問を端末内で提案

## データについて

人物データはブラウザのIndexedDBに保存し、外部へ送信しません。PINは画面を開きにくくする簡易ロックで、保存データ自体の暗号化ではありません。重要なデータは設定画面から定期的にバックアップしてください。

名刺の自動文字読み取りはブラウザのTextDetector対応端末に限られます。非対応端末でも名刺画像を人物写真として保存し、手入力できます。
